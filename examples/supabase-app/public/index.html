What just happened

  1. You proved you control an inbox with a one-time code.
  2. This server asked the gateway who that address belongs to. The gateway read users.email — a field its own field policy hides from the model — and answered with a user id and a role.
  3. It set an httpOnly session cookie holding that id and role. Nothing else.
  4. The widget asked this server for a chat token; the server called the gateway with its secret key and asserted your id and role. The browser never sees either.
  5. Every question is answered under that role — the filter is forced onto the database query in code, so no phrasing gets around it.
